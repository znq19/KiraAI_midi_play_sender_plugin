# 🎹 MIDI演奏语音条（midi_play_sender）v1.1.0

一个给 **KiraAI** 机器人用的插件：你说一首歌名，它**搜索 MIDI 谱 → 用合成器弹出来 → 直接发成 QQ 语音条**。

> 你说"来首钢琴版的 未闻花名"，等十几秒，你的 QQ 里就出现一条机器人弹的钢琴语音条。就这么简单。

---

## ✨ 它能干什么

| 你这样做 | 机器人会 |
|----------|----------|
| 说 **"弹一首XXX / 来首钢琴版 / MIDI演奏"** | 自动搜索 MIDI 谱，合成演奏，发语音条 |
| 说 **"用八位机音色弹XXX"** | 换音色演奏（默认钢琴，可选吉他/管风琴/八位/弦乐/铃/长笛等） |
| **直接发一个 `.mid` 谱子文件** | 当这条消息唤醒了 AI（bot 回复你）时会**顺便静默**存入谱库，之后说"弹奏 文件名"就能演奏它 |
| 说 **`/弹奏 曲名`** | 不走 AI，直接搜+弹+发 |

## 🎬 效果示例

```
你：来首钢琴版的 打上花火
机器人：好嘞，在弹了，稍等~
（十几秒后）语音条到账 🎧
机器人：《打上花火》弹好了，请听~
```

> 💡 因为合成演奏需要十几秒到几十秒，插件是**异步渲染**的：机器人先回你"在弹了"，弹完自动把语音条发出来并补一句"弹好了"——不会让你干等，也不会卡住对话。

## 📦 安装方法（小白版，3 步）

1. **下载** 整个 `midi_play_sender` 文件夹。
2. **上传** 到服务器 KiraAI 的 `data/plugins/` 目录（文件夹名字别改）。
3. **启用**：插件管理里打开「MIDI演奏语音条」开关；或者重启 KiraAI 自动加载。

> 💡 依赖（mido/numpy/scipy/soundfile）会在启用时**自动安装**，第一次可能等一两分钟。
> ⚠️ 如果安装 soundfile 后渲染报"OGG/Opus 不支持"错误，说明该版本 libsndfile 缺 Opus 支持，把 requirements.txt 里 soundfile 固定为 `soundfile==0.14.0` 再重装即可。

## ⚙️ 配置说明（看不懂的可以全部不动，默认就能用）

**基础设置**

| 配置项 | 默认 | 说明 |
|--------|------|------|
| 启用LLM工具调用 | **开** | 让机器人听懂"弹一首XXX"。关掉后只能靠命令词 |
| 启用命令词触发 | 关 | 打开后才能用 `/弹奏` `/弹琴` |
| 命令词列表 | `/弹奏`、`/弹琴` | 每行一个 |
| 默认乐器 | piano | 没指定乐器时的默认音色（下拉选择） |

**权限白名单（仅对命令式生效）**

| 配置项 | 默认 | 说明 |
|--------|------|------|
| QQ号白名单 | 空 | 空=不限制；填了只有名单内能用 `/弹奏` |
| 群号白名单 | 空 | 同上，按群限制 |

**搜索与候选**

| 配置项 | 默认 | 说明 |
|--------|------|------|
| 候选谱条数 | 5 | 搜索返回几条候选 |
| 自动取第一条直下 | 关 | 关=机器人自己挑或发给你选；开=直接弹搜索结果第一条 |

**渲染**

| 配置项 | 默认 | 说明 |
|--------|------|------|
| 曲谱时长上限 | 600 | 超过 10 分钟的谱不渲染（省时间和流量） |
| 网络请求超时 | 60 | 搜索/下载超时时间 |

**缓存**

| 配置项 | 默认 | 说明 |
|--------|------|------|
| 谱库目录 | `files/midi_lib` | MIDI 谱文件放这，**默认永不删除**（与渲染缓存分离，防误删） |
| 渲染缓存目录 | `files/midi_cache` | 渲染好的音频放这，重复点歌秒发 |
| 永久保留MIDI谱 | **开** | 开=谱子永不参与自动清理；关=谱子也按缓存上限清理最旧 |
| 外部谱子自动入谱库 | **开** | 开=本地路径/直链/其他方式获得的谱子自动复制一份到谱库，下次点歌直接命中；关=直接用原文件，不占谱库空间 |
| 缓存文件上限 | 50 | 超过自动清理最旧的（渲染缓存；谱库仅在"永久保留MIDI谱"关闭时参与） |
| 单次清理数量 | 20 | 每次清理删几个 |

## ❓ 常见问题（FAQ）

**Q：等了很久没收到语音条？**
A：长一点的曲子渲染要 30~60 秒，正常。如果超过 2 分钟还没动静，可能是渲染失败，机器人会发一条"演奏失败"说明原因。

**Q：提示"没找到谱子"？**
A：换个更常见的歌名/加歌手名试试（比如"River Flows in You 钢琴"）。中文名容易搜不到，试试英文名（如 Canon in D）。你也可以直接发一个 `.mid` 谱子文件给机器人——只要这条消息唤醒了 AI，谱子会**顺便静默**存进谱库（不发确认消息，避免打扰），之后说"弹奏 文件名"就能用。

**Q：机器人能下载我给的链接/文件吗？**
A：能。支持任意直链（Google Drive 等，只要链接直接给 MIDI 文件）、谱子页面（会自动提取下载链接）、以及 QQ 里直接发的 `.mid` 文件（该消息唤醒 AI 时自动入库）。

**Q：提示"超过上限"？**
A：曲子太长（默认超 10 分钟不渲染）。可以在配置里调大"曲谱时长上限"。

**Q：提示"不在白名单"？**
A：白名单只影响 `/弹奏` 命令。要么把自己 QQ 加进白名单，要么清空白名单（清空=不限制）。

**Q：渲染报"OGG/Opus"错误？**
A：见上方安装说明第 3 步的 ⚠️，把 soundfile 固定版本重装。

**Q：会占用很多 token 吗？**
A：刻意做了优化：工具只做快的搜索下载，渲染放后台；完成后只触发一次 LLM 回复。重复点同一首曲子走缓存，不重复渲染。

## 📝 技术说明（给好奇的人）

- **搜索谱子**：优先 BitMidi 站内搜索（返回的页面 100% 真实可下载），FreeMidi 搜索兜底（bitmidi 无谱时自动切换），多层容错。
- **下载谱子**：BitMidi 歌曲页 → `/uploads/数字.mid`；FreeMidi 详情页 → `/getter-{id}`（需先访问详情页拿 session cookie + Referer，否则 500）。
- **合成**：纯 Python 正弦波合成器（带谐波与包络），无 ffmpeg、无 MIDI 音源库。
- **编码**：44.1kHz 合成 → 重采样 24kHz → **OGG Opus**（体积约 WAV 的 5%，5 分钟约 2-3MB）。
- **异步**：渲染在后台线程跑，不阻塞 QQ 消息收发；完成后自动发语音条 + 触发机器人回复。
